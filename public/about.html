About Our Food Ordering System

This project is a Food Ordering System developed using HTML, CSS, JavaScript and Node.js. It allows users to register, login, browse food items, add them to cart and place orders easily.

The main objective of this project is to provide a simple and user-friendly interface for online food ordering. It also demonstrates the use of frontend and backend technologies.

Features include user authentication, cart management, order placement and responsive design.
