\# Food Ordering System



A simple web-based Food Ordering System developed using Node.js, Express.js, HTML, CSS, JavaScript, and MongoDB.



\## Features



\- User Registration

\- User Login

\- User Profile

\- Food Menu

\- Add Food Items to Cart

\- View Cart

\- Place Orders

\- About Us Page

\- MongoDB Database Integration



\## Technologies Used



\- HTML

\- CSS

\- JavaScript

\- Node.js

\- Express.js

\- MongoDB

\- Mongoose
